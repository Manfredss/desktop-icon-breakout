**下载对应系统的 ZIP / tar.gz，完整解压后打开游戏。无需安装 Python 或 .NET。**

- 全部砖块来自真实桌面、已安装软件或原生系统图标；图标不够，借本机软件补齐。

## Your icons have been reassigned to brick duty.

**Download the ZIP / tar.gz for your OS, extract it completely, and open the game. No Python or .NET install required.**

- Real desktop, installed-app, and native system icons. No invented software logos.
- Windows, Apple Silicon Mac, Intel Mac, and Linux packages.
- English / Chinese, combos, three pickups, continuous levels, auto-pause.
- Fully offline gameplay. Your actual files and desktop layout remain untouched.
- Mac builds are ad-hoc signed, not Developer ID signed/notarized; Linux needs glibc 2.35+ and a desktop graphics environment. Mac/Linux currently play silently.

Windows: `DesktopIconBreakout.exe` · macOS: `DesktopIconBreakout.app` · Linux: `./DesktopIconBreakout`

SHA-256 files accompany every package. Source and bilingual instructions are in the repository.
